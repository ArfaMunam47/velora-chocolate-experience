# VELORA — Luxury Chocolate Experience

**velora-chocolate-experience** is a premium landing page concept built to showcase an artisanal chocolate brand through rich visual storytelling and immersive 3D presentation.

## ✨ Project Overview

This project is designed as a luxury boutique experience for VELORA, blending elegant typography, cinematic dark luxury styling, and a layered 3D product showcase.

- **Brand**: VELORA
- **Theme**: High-end confectionery, handcrafted chocolate
- **Visual style**: Deep cocoa palette, glowing gold accents, soft cream textures
- **Interaction**: Smooth scroll reveal, animated product highlight, 3D fallback support, responsive navigation

## 🌟 What Makes It Premium

- Full-screen luxury hero with custom typography and refined spacing
- 3D WebGL-enhanced chocolate presentation using `three.js`
- Intentional motion design for subtle parallax, hover, and reveal effects
- Handcrafted brand palette and atmosphere with premium finishes
- A clean interface focused on storytelling, product, and sensory details

## 🧱 Core Experience

1. **Hero section** with an immersive product focus and elegant brand messaging
2. **3D product rendering** that highlights chocolate craftsmanship in a sculptural, editorial style
3. **Responsive navigation** with adaptive mobile menu behavior and soft transitions
4. **Interactive details** like add-to-cart toasts, contact form feedback, and scroll reveal animations

## 🛠️ Key Files

- `.vscode/path/index.html` — the branded landing page markup, meta, and hero content
- `.vscode/path/main.js` — page behavior, UI interactions, contact toast, and 3D initialization
- `.vscode/path/sceneSetup.js` — `three.js` renderer, lighting rig, and shadow surface setup
- `.vscode/path/chocolateModel.js` — custom product model construction and material styling

## 🎨 Design Direction

This project is intentionally crafted to feel luxurious and premium:

- Cocoa-based deep neutrals with elegant gold highlights
- Classic serif headline typography paired with modern sans-serif text
- Soft ambient lighting, grain textures, and subtle vignette overlay
- Minimal UI chrome to keep focus on product and story

## 🚀 Usage

1. Open `index.html` in a browser that supports WebGL
2. If WebGL is unavailable, the page gracefully renders a polished fallback experience
3. Interact with the menu, scroll through the story sections, and explore the product details
